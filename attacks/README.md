# Attacks (Phase 1+)

This directory is reserved for memory poisoning attack implementations.

## Planned Attack Vectors
- **Direct Memory Injection**: Poisoning user prompt instructions to force malicious memory writes.
- **Indirect Memory Poisoning**: Introducing untrusted third-party tool outputs (e.g. malicious invoice notes, crafted support ticket payloads) that persist malicious instructions into the vector or structured stores.
- **Context Hijacking**: Manipulating recalled context to override system prompt boundaries.

*Phase 0 status: Scaffold only. No attack logic is active.*
