# Evaluation Harness (Phase 3+)

This directory will house automated benchmarks, metrics, and evaluation scripts.

## Evaluation Goals
- Measure Attack Success Rate (ASR) on target models and prompts.
- Evaluate defense latency and false positive rates (FPR) on legitimate memory persistence.
- Parse structured JSONL logs in `logs/` to trace memory poisoning propagation.
